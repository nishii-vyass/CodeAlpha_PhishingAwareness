# CodeAlpha Phishing Awareness Training

## CodeAlpha Cyber Security Internship — Task 2

This project is an interactive web-based **Phishing Awareness Training Module** created as part of the CodeAlpha Cyber Security Internship.

The purpose of this project is to educate users about phishing attacks and teach them how to recognize suspicious emails, fake websites, social-engineering techniques, and other common phishing indicators.

---

## Project Objectives

This project focuses on:

* Understanding phishing attacks
* Identifying phishing emails
* Identifying suspicious/fake websites
* Understanding social-engineering tactics
* Learning phishing prevention techniques
* Studying phishing examples
* Testing user knowledge through an interactive quiz

---

## Features

### 1. Phishing Awareness

Explains:

* What phishing is
* How phishing attacks work
* Why attackers use phishing
* Common consequences of phishing

### 2. Types of Phishing

The module explains:

* Email phishing
* Spear phishing
* Smishing
* Vishing
* Clone phishing
* Fake websites

### 3. Phishing Email Detection

Users learn to identify:

* Suspicious sender addresses
* Urgent messages
* Suspicious links
* Unexpected attachments
* Requests for passwords or OTPs
* Payment requests

### 4. Fake Website Awareness

The module teaches users to inspect:

* Domain names
* URLs
* Login pages
* Unexpected requests
* Website context
* Suspicious spelling or branding

### 5. Social Engineering

The project explains common psychological manipulation techniques:

* Urgency
* Fear
* Authority
* Curiosity
* Reward
* Trust
* Scarcity

### 6. Safety Practices

Users learn how to:

* Verify suspicious requests
* Avoid unexpected links
* Use multi-factor authentication
* Protect passwords
* Keep software updated
* Report suspicious messages

### 7. Phishing Examples

The project contains fictional phishing examples for awareness training.

### 8. Interactive Quiz

The website includes a JavaScript-powered quiz that calculates the user's score and displays feedback.

## How to Run

1. Open the `web` folder.
2. Double-click `index.html`.
3. The training module will open in your web browser.
4. Read the training sections.
5. Complete the interactive quiz.
6. Check your final score.

No server installation is required.

---

## Interactive Quiz

The quiz is implemented using JavaScript.

The system:

1. Displays questions.
2. Accepts user answers.
3. Checks answers.
4. Calculates the score.
5. Displays feedback.

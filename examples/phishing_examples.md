# Phishing Awareness Examples

> **Important:** The examples below are fictional training examples. They are intentionally non-functional and must not be used to impersonate real organizations or collect credentials.

---

# Example 1 — Fake Account Verification

### Subject

**URGENT: Account verification required**

### Message

> Your account requires verification today. Failure to verify may result in restricted access.

### Warning Signs

* Urgent language
* Unexpected verification request
* Pressure to act quickly
* Possible suspicious link

### Safe Response

Do not use the link from the message.

Open the service using its known official website or application.

---

# Example 2 — Fake Delivery Message

### Subject

**Delivery problem — action required**

### Message

> We could not complete your delivery. Confirm your information to reschedule the delivery.

### Warning Signs

* Unexpected delivery message
* Request for information
* Lack of normal order context
* Pressure to take action

### Safe Response

Check the order using the official retailer or delivery service application.

---

# Example 3 — Fake IT Support Message

### Subject

**Password expires today**

### Message

> Your password will expire today. Contact IT using the information provided in this message.

### Warning Signs

* Artificial deadline
* Unexpected password request
* Contact information supplied by the suspicious message

### Safe Response

Contact the organization's IT department using its normal official help-desk process.

---

# Example 4 — QR Phishing

A message asks a user to scan a QR code to verify an account.

### Warning Signs

* Unexpected QR code
* Urgent request
* Hidden destination
* Possible login request

### Safe Response

Do not scan unexpected QR codes.

Navigate to the official service yourself if verification is actually required.

---

# Example 5 — Fake Reward

### Subject

**Congratulations! You have won a reward**

### Message

> You have been selected for a special reward. Confirm your details immediately to claim it.

### Warning Signs

* Unexpected reward
* Request for personal information
* Urgency
* Unknown sender

### Safe Response

Do not provide personal information.

Verify the claim through the organization's official website.

# Real-World Case Study Template

For verified public incidents, document:

### What happened?

Briefly describe the incident.

### What technique was used?

Explain the phishing or social-engineering method.

### What warning signs existed?

List the indicators that users could have noticed.

### What is the security lesson?

Explain what users and organizations can do to reduce similar risks.

Only use verified public sources when adding specific real-world incidents to the final presentation.
